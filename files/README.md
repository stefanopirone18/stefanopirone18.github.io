# Cartella `files`

Tutto ciò che metti qui è pubblico e raggiungibile all'indirizzo `/files/...`.

- **CV**: sostituisci `cv-stefano-pirone.pdf` con il tuo CV, mantenendo lo stesso
  nome file. I pulsanti "CV (PDF)" del sito puntano già a questo percorso.
- **PDF di progetto**: caricali qui (es. `files/monitoraggio-whistleblowing.pdf`) e
  collegali dalla card in `public/data/content.js`:
  `link: { url: "/files/monitoraggio-whistleblowing.pdf", etichetta: "Leggi il report" }`
- **Prototipi HTML autonomi**: mettili in `files/prototipi/` (es.
  `files/prototipi/capacita-nussbaum.html`, con eventuali file CSS/JS accanto) e
  collegali con `link: { url: "/files/prototipi/capacita-nussbaum.html", etichetta: "Apri il prototipo" }`.

Usa nomi file in minuscolo, senza spazi né accenti (es. `report-trasparenza-2026.pdf`).
